m# Quiz_app_simple
simple quiz app _with final score  &amp; Reset quiz
___frist project  using flutter widgets

 ## ✨ Features

- Multiple-choice quiz questions
- Score calculation
- Final result screen
- Restart quiz functionality
- Clean and responsive UI
- Built using Stateful Widgets and reusable components


## without 
-quiz timer

##---------widgets --------##
-StatefulWidget
-StatelessWidget

-Scaffold     إنشاء الهيكل الأساسي لشاشة التطبيق

-Padding            إضافة مسافات حول العناصر        

-Column                  ترتيب العناصر رأسي  

-Row                      ترتيب العناصر أفقي   
------------
-SizedBox       إضافة مسافات وتحديد أبعاد العناصر

-Center              توسيط العناصر داخل الشاشة

-Spacer       توزيع المسافات بين العناصر بشكل مرن

-Icon                         عرض الأيقونات 

-text                         عرض النصوص 
------------
-ElevatedButton          زر الانتقال إلى السؤال التالي

-TextButton                      زر إعادة الاختبار  

-InkWell            اكتشاف ضغط المستخدم على الإجابات  

-DecoratedBox تنسيق عناصر الإجابات وإضافة الحدود والألوان

-List.generate()      إنشاء قائمة الإجابات بشكل ديناميك
